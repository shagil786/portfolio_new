# Fine-tuning MSN AI's routing model (Needle 2)

The on-device chat runs a 45M-parameter Needle 2 model. Two weight files ship
in `public/needle/`:

- `needle2.cact` — the base model (13.7 MB)
- `tuned.cact` — LoRA fine-tuned on this portfolio's Q&A (13.7 MB, **shipped**)

The worker (`public/needle/worker.js`) prefers `tuned.cact` and falls back to
the base when absent, so deployments always work.

## The dataset

`data.jsonl` — 58 examples in Needle's training format, generated by
`python3 finetune/generate.py` from:

- the resume PDFs (role, employers, My Money 5M+ accounts, Light Year CMS
  40% publishing-time cut, Credit Card Comparison, agentic UI delivery
  workflows, Finbox loan-origination/Deviation module/micro-frontends,
  Fincity SaaS platform + drag-and-drop builder), and
- the 11-tool registry: 7 read tools (profile, experience, projects, skills,
  achievements, education, contact) + 4 UI action tools (set_theme,
  set_muted, open_section, toggle_recruiter).

Tool schemas in the dataset must stay in sync with `src/lib/agentTools.ts`
(single source of truth for the shipped registry). To synthesize more
examples with an LLM (optional, needs an API key):

```sh
export OPENROUTER_API_KEY=sk-or-...
needle generate-data --tools <tools-as-json> --num-samples 500 --output finetune/data.jsonl
```

## Retrain

```sh
pip install "cactus-needle[train]"
needle finetune finetune/data.jsonl --epochs 12 --checkpoint-dir /tmp/needle-tune
needle build checkpoints/needle2.pkl --lora /tmp/needle-tune/needle_lora.pkl
cp needle2.cact public/needle/tuned.cact
```

## Measured impact (base vs tuned)

Multi-sample probe (`node finetune/compare.cjs` — 10 queries × 5 samples,
correct routing = right tool + right argument):

| query                      | base | tuned |
| -------------------------- | ---- | ----- |
| mute the sounds            | 5/5  | 1/5   |
| recruiter mode             | 0/5  | 4/5   |
| turn sound on              | 0/5  | 0/5   |
| change color to blue       | 0/5  | 4/5   |
| make it purple             | 0/5  | 0/5   |
| what did he do at finbox?  | 0/5  | 0/5   |
| how can I contact him?     | 2/5  | 1/5   |
| what is his email?         | 0/5  | 4/5   |
| does he know react?        | 0/5  | 0/5   |
| what impact did he have?   | 0/5  | 0/5   |
| **TOTAL**                  | 7/50 | 14/50 |

The tuned weights double overall routing accuracy. Sampling is noisy on a 45M
model, so the deterministic layers matter: the action matcher
(`src/lib/agent/actions.ts`) guarantees color/sound/navigation requests work,
and the scripted bot + knowledge graph answer open-ended data questions the
model still misses.

## Caveats

- Fine-tuning does not update Needle's confidence head; tuned scores are
  uncalibrated. The pipeline treats missing/uncalibrated confidence as
  pass-through and still validates every tool call through governance.
- `tuned.cact` is a binary artifact in git (13.7 MB, same footprint as the
  base) — regenerate it with the retrain steps above, never edit by hand.

## Verify after retraining

- `node finetune/compare.cjs` — compare against the base on the probe set.
- `npm test` — the engine e2e test exercises the real shipped assets.
- In the browser: "make it purple" → theme cycles, "mute the sounds" → muted,
  "recruiter mode" → resume view, "what did he do at finbox?" → experience.
